# Academic Management System Backend

Цей проєкт є серверною частиною системи управління академічною структурою, побудованою на базі Django REST Framework (DRF) та повністю контейнеризованою за допомогою Docker та Docker Compose для забезпечення швидкого розгортання та ізоляції середовища розробки.

## Швидкий запуск проєкту в Docker

Для підняття та збірки всієї інфраструктури, що включає сервер додатку Django та СКБД PostgreSQL 15, використовується єдина команда. Переконайтеся, що Docker Desktop запущено у вашій системі, відкрийте термінал у корені проєкту та виконайте команду збирання й запуску:

docker compose up --build

Після успішного завантаження образів та ініціалізації бази даних локальний сервер автоматично почне слухати порт 8000 і буде доступний за адресою http://localhost:8000/. Завдяки налаштованим Docker Volumes, будь-які зміни в коді бекенду на хост-машині миттєво синхронізуються з контейнером без необхідності повторного перезапуску команди.

## Первинне налаштування бази даних

Оскільки база даних PostgreSQL запускається в ізольованому контейнері з нуля, під час першого старту проєкту необхідно згенерувати структуру таблиць та створити обліковий запис адміністратора. Для цього відкрийте паралельне вікно терміналу та виконайте послідовно дві команди.

Перша команда застосовує наявні міграції Django до бази даних:
docker compose exec web python manage.py migrate

Друга команда реєструє суперкористувача для доступу в панель керування:
docker compose exec web python manage.py createsuperuser

Під час виконання команди створення суперкористувача термінал послідовно запитає бажане ім'я користувача, електронну пошту та пароль. Символи пароля під час введення в консоль не відображаються з міркувань безпеки, тому введення здійснюється наосліп з подальшим натисканням клавіші Enter.

## Основні точки доступу та документація API

Після успішного виконання міграцій та запуску контейнерів стають доступними два основні веб-інтерфейси системи.

Адміністративна панель Django доступна за адресою http://localhost:8000/admin/ і є веб-інтерфейсом для керування обліковими записами, структурою філій, академічними групами, розкладом занять, предметами та журналами відвідуваності студентів.

Документація API у форматі Swagger UI доступна за адресою http://localhost:8000/api/schema/swagger-ui/ і є інтерактивною специфікацією OpenAPI 3.0, яка згенерована автоматично за допомогою пакета drf-spectacular. Вона відображає всі доступні API-ендпоінти, схеми очікуваних даних, правила серіалізаторів та дозволяє тестувати запити до бекенду прямо з браузера після передачі JWT-токена авторизації.

## Технологічний стек проєкту

Проєкт реалізовано з використанням сучасного та стабільного інструментарію розробки бекенд-систем. Як основна бекенд-платформа виступає зв'язка мови Python 3.11-slim та фреймворків Django 5.x разом із Django REST Framework. Для надійного збереження даних інтегровано офіційний Docker-образ системи керування базами даних PostgreSQL 15. Процес автентифікації користувачів і захисту ендпоінтів побудовано на базі протоколу JSON Web Tokens за допомогою розширення Simple JWT. Автоматична генерація схем та інтерактивної документації реалізована через бібліотеку drf-spectacular. Уся архітектура додатку оркеструється інструментами Docker та Docker Compose, що гарантує ідентичність оточення розробки на будь-якій локальній машині.
